# 单窗口模式（v0.3.1）设计记录

> 这是插件最早的工作方式，也是 `multi.enabled = false` 时的行为。
> 代码基线：`git show v0.3.1:lib/poller.js`（标签 `v0.3.1`）。
> 多窗口设计见 [`wechat-multichat-design.md`](wechat-multichat-design.md)。

## 一句话

**只盯一个群**：轮询始终停在这个群里，看有没有新消息，有就叫醒模型决定回不回；
不在这个群就去搜索进入；不扫列表、不去别的会话。

## 核心循环

```
startPolling()
  ├─ 慢轮 intervalSec(15/30s)：无论屏幕变没变，跑一次 capture()
  └─ 快轮 probeSec(4s)：只读微信的渲染帧计数（~140ms）
        └ 帧计数变了才跑 capture()（屏幕真动了才截图）
```

`capture()` 做这些事：

1. `dumpsys window` 看前台是不是微信；
2. 不在白名单那个群 → `tryAutoOpen()`（回列表 → 搜索 → 点第一条），本轮结束；
3. 截图 + 像素哈希；没变化直接返回（不跑 OCR）；
4. 动图判定：`frame_diff.py` 看变化带是不是同一条（同处还在动 = 动图，不算新消息）；
5. 识别：`rapidocr` / `windows` / `qwen-vl` 三选一，读出「昵称：内容」逐行文本；
6. 差分：只保留上一帧没有的行；
7. 去重：`seen.json` 里 30 分钟内出现过的行不算新；自己 15 分钟内发过的不算新；
8. 判定：本地 4B 判官（`judge_worth.py`）给一个「值得回 / 不值得回」；
9. 唤醒：`schedule.create` 往绑定会话投一条一次性任务，prompt 里带新消息原文；
10. 冷却：普通消息 `wakeCooldownSec`（90s）合并；@ 用 15s 短窗口；
    冷却期间的新消息攒进 `pendingText`，冷却一过一起发。

## 讨论串（v1 版本）

- 有人 @ → 开一条串，把「@ 之前那几句」当上下文写进 prompt；
- 串没过期（`threadTtlMin` 默认 10 分钟**没新消息**）→ 这个群里的新消息都算续聊；
- 串内两条发言至少隔 `threadGapSec`（20 秒）；
- 自己主动搭话也算开串（先登记 pending，真发出去了才成立）。

**v1 的续命判据是"这个群里有新消息"**，不是"对着她说的"——因为轮询只在这个群里，
群里说话就是她的语境。多窗口模式改了这条（见多窗口文档）。

## 主动参与（v1）

- 有 @ → 必须回；
- 串活着 → 可以接着聊；
- 都没有，但距上次发言/参与已满 `noMentionIntervalMin`（30 分钟）→ 可以自己搭一句；
- 都不满足 → 只 ack，不叫醒。

## 消息从哪来、到哪去

```
手机屏幕 ──adb screencap──> 本地 OCR/判官 ──> prompt ──> DSH 会话（wakeSessionId）
                                                            │
                                                    wechat_send（发到当前打开的会话）
```

因为始终停在同一个群，"发到当前会话"就等于"发到那个群"。
多窗口模式打破了这个前提，才有了 `wechat_send` 的 `chat` 参数与发送前核对。

## 已知的取舍

| 取舍 | 后果 |
|---|---|
| 只盯一个群 | 别的群/私聊的新消息完全看不到 |
| 不在目标群就搜索进入 | 屏幕上会看到"回列表 → 搜索 → 点进去"的动作 |
| OCR 逐帧差分 | 本地 VL 对同一行措辞会抖（"脆脆"/"脆皖"），需要归一化（多窗口版加的） |
| 识图描述每帧都变 | 动图/图片会让差分一直"有新内容"（多窗口版加的归一化） |
| 串续命看"群里有新消息" | 热闹的群会把一个串续很久（多窗口版的"只认对着她说"解决了） |

## 与多窗口模式的开关

设置页顶部「会话模式」= `multi.enabled`：

- **关** → 本文件描述的行为（死盯 `whitelistChats[0]`）；
- **开** → 多窗口模式（扫列表挑会话、白名单、私聊开串、发送核对…）。

代码里所有多窗口分支都写在 `multiOf(cfg).enabled` 后面；单窗口路径保持 v0.3.1 的形状。
